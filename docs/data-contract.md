## 一、数据行结构

| 项 | 约定 |

## 二、量纲判定（任务 0.2 结论）

### 判据

以「数据峰值 ÷ 空调面积」是否落在同类建筑合理区间（80–200 W/m²）判定，并以「年累计冷量 ÷ 空调面积」交叉验证（办公建筑供冷 40–90 kWh/m²·yr）。

### 实测

| 量 | 原始值 | 若单位 = W | 若单位 = kW |
|---|---|---|---|
| 逐时峰值负荷 | 303,067.16 | 303.07 kW → **103.40 W/m²** ✅ | 303,067 kW → 103,401 W/m² ❌ |
| 年累计冷量 | 149,646,120 | 149,646 kWh → **51.06 kWh/m²·yr** ✅ | 149,646,120 kWh → 51,056 kWh/m²·yr ❌ |
| 设计峰值负荷 `load_building_r` | 196,572.0 | 196.57 kW → **67.07 W/m²** ✅ | 196,572 kW → 67,067 W/m² ❌ |

**结论：数据列与设计负荷的单位均为 W，不是文件表头声明的 kW。**

### 换算系数

```
load_coe = 1 / 1000        # W -> kW
```

默认值由 `1/26.58`（原值）改为 `1/1000`，改动依据与影响见 `design.md` D8。

## 三、装机的尺度问题

按 kW 口径，本建筑的设计负荷为 **196.57 kW**，而默认选型的装机容量为：

```
3 × 2112.6 + 1 × 1056.3 = 7,394.1 kW  ->  2,522.7 W/m²
```

典型办公建筑装机为 100–150 W/m²，**默认装机超配约 24–38 倍**。

原 `1/26.58` 的真实作用不是量纲换算，而是把装机"缩"到设计负荷的 1.415 倍：

```
7,394.1 / 196.572 = 37.61（超配倍数）
37.61 / 26.58     = 1.415（重标定后的设计余量）
```

### 重标定后的合理选型

| 设备 | 原默认值 | 重标定（÷26.58） |
|---|---|---|
| 大冷机额定制冷量 | 2,112.6 kW × 3 | **79.5 kW × 3** |
| 小冷机额定制冷量 | 1,056.3 kW × 1 | **39.7 kW × 1** |
| 合计装机 | 7,394.1 kW | **278.2 kW**（设计负荷的 1.415 倍） |
| 大机冷冻泵设计流量 | 100.9 L/s | **3.80 L/s** |
| 小机冷冻泵设计流量 | 50.5 L/s | **1.90 L/s** |
| 大机冷却泵设计流量 | 126.1 L/s | **4.74 L/s** |
| 小机冷却泵设计流量 | 64.0 L/s | **2.41 L/s** |
| 大机冷却塔设计流量 | 200.0 L/s | **7.52 L/s** |
| 小机冷却塔设计流量 | 100.0 L/s | **3.76 L/s** |

水泵扬程与冷却塔压降属水力阻力参数，不随容量等比缩放，保持原值。

重标定后，数据峰值 303.07 kW 略高于装机 278.2 kW（+8.9%），属于设计工况（31.7 ℃）与实际极值（37.2 ℃）之差，该部分应以「供冷缺口」形式显式输出，见 `specs/simulation-result`。

## 四、与设备模型的尺度约束（关键）

三个设备模型均为 ML 代理模型，其**训练域绑在 7.4 MW 参考机组**上：

| 模型 | 输入 | 是否无量纲 | 能否直接缩放 |
|---|---|---|---|
| 冷机 | 负荷率、供/回水温度 | 是 | 可以，按额定容量线性缩放功率 |
| 水泵 | 流量 G (L/s)、扬程 H (mH2O) | **否** | 不可以，须做相似换算 |
| 冷却塔 | 水流量 Gw、风量 Ga、室外工况 | **否** | 不可以，须做相似换算 |

实测证据：把设备直接 ÷26.58 而不做相似换算时，水泵流量被模型硬下限（`G_min = 182.46 × 0.6 = 109.48 L/s`）强制拉高 28.8 倍，冷却塔风量被拉到 `Ga_min = 23,564 m³/h`，导致全年能耗由 1,069,854 kWh 暴涨至 **67,504,888 kWh**（63 倍），系统能效降至 0.0022。

因此**设备重标定必须与相似换算同批实施**，见 `design.md` D5。
