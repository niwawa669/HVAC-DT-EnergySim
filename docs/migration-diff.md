## 二、A → B：代码修复带来的变化（参数不变）

| 差异 | 幅度 | 归因决策 |
|---|---|---|
| 计算小时数 8,736 → 8,760 | +24 h（+0.27%） | **D1 / D2**：按日历周分组，尾部不满一周的记录显式参与计算，不再被 `range(1,53)` 截断 |
| 总冷负荷 149,645,504 → 5,626,694 | ÷26.58 | **D8**：冷负荷统一换算到 kW 口径，与供冷量可比（此前两者相差 26.58 倍） |
| 总能耗 1,069,854 → 926,906 | −13.4% | **D5**：额定值由选型参数注入。原代码让小机通道沿用大机额定值，小机功率被算了 **2 倍**，修复后降为正确值 |
| 冷机平均 COP 7.05 → 8.66 | +22.8% | **D5**（同上，小机功率修正直接抬高平均 COP） |
| 供冷缺口 19,714 kWh / 7 h | 新增可见项 | **D6**：`Q_served = min(需求, 已投运装机)`，超出部分不再被钳制后冒充已满足 |
| 分项能耗可分解 | 新增 | **D3 / D4**：四合项在服务层累加，此前被合并成单一总值 |
| 碳排 534,927 → 514,803 | −3.8% | **D10**：因子 0.5 → 0.5554（+11.1%），同时能耗下降 13.4%，净降 |

## 三、B → D：口径变更带来的变化（代码不变）

| 差异 | 幅度 | 归因决策 |
|---|---|---|
| 总冷负荷 5,626,694 → 149,646 | ÷37.6 | **D8**：`load_coe` 由 `0.0376` 改为 `0.001`（W→kW 的真实换算） |
| 装机容量 7,394.1 → 278.18 kW | ÷26.58 | **D8 / 6.6**：设备默认值重标定，使装机/设计负荷 = 1.415 |
| 总能耗 926,906 → 26,244 | ÷35.3 | **D8**：负荷 ÷37.6 与装机 ÷26.58 的复合效果（负荷率下降 0.707 倍，部分负荷工况占比上升） |
| EUI 316.2 → 8.95 | ÷35.3 | **D8**（同上） |
| 供冷缺口 19,714 → 58.33 kWh | −99.7% | **D6 / 6.6**：装机相对负荷放大 1.415 倍后，超装时段从 7 小时降到 3 小时 |
| 系统能效 5.94 → 5.54 | −6.7% | **D7 / 6.1**：泵/塔功率改按"设备自身台数"累加，部分负荷下比按冷机台数累加耗电更多 |

## 四、无差异项（确认未受影响）

- **冷机平均 COP 8.66 → 8.56**：D8 的线性额定缩放保持 COP 不变，仅有边际差异，来自负荷率分布变化。
- **计算小时数**：B 与 D 均为 8,760，说明口径变更不影响覆盖范围。

## 五、无法归因的差异

无。上列每一项均可对应到 `design.md` 的具体决策编号。

## 六、遗留说明

- **碳排因子为 2023 年北京省级口径（0.5554）**。若改用全国口径（0.5306）或华北区域口径（0.6361），碳排放会分别变化 −4.5% / +14.5%，`meta.carbonFactor` 会记录实际命中的层级。
- **EUI 8.95 kWh/m²·yr 对应的是"空调供冷"这一项**，不含采暖、照明与设备，不可与建筑总能耗指标直接比较。
