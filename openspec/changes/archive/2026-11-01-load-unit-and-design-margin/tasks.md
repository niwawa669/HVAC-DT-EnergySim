## 2. 算法层：删除换算与旧缩放，引入统一放大系数（D5）

- [x] 2.1 删除 `load_coe`：`StationInfo.load_coe` 移除，`station.__call__` 不再乘系数，`ChannelInfo.load_coe` 一并删除；验证：以同一份数据运行，结果中的冷负荷总量等于数据负荷之和（不再缩小 1000 倍）
- [x] 2.2 删除冷机旧缩放：移除 `Chiller.scale_applied / scale_ratio` 与功率缩放；验证：额定容量等于 2112.6 时输出与删除前逐位一致
- [x] 2.3 删除水泵/冷却塔旧相似换算：移除 `kG / kH / kGw / kGa` 与输入折算、输出放大；验证：参考额定值下与删除前逐位一致（用模型数值指纹对比）
- [x] 2.4 引入统一放大系数 N（默认 20.0）：冷机输出功率 × N；水泵输入流量 ÷ N、输出功率 × N；冷却塔输入水量与风量 ÷ N、输出风机功率 × N；验证：N=1 时结果与"未引入系数"逐位一致；N=2 时冷机、水泵、冷却塔三项功率均恰为 N=1 的 2 倍（容差 1e-6）
- [x] 2.5 实际单机容量 = 2112.6 × N，并用于负荷率与设计裕度计算；验证：N=20 时单机容量为 42,252 kW，且冷机负荷率仍落在 [0,1]
- [x] 2.6 三个模型的尺度一致性：验证同一 N 下冷机、水泵、冷却塔的功率放大倍数相同，不得出现某一项用了不同的 N
