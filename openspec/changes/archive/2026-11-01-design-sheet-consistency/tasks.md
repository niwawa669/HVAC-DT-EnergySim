## 1. 后端派生与请求精简（D1/D2）

- [x] 1.1 新增派生函数：`cop_at_design(Q, tr_chw, ts_chw, tr_cw, ts_cw)`，调用冷机模型在满负荷求功率并返回 `Q ÷ P`；验证：默认配置下大机与小机均返回 6.8235（±1e-4）
- [x] 1.2 新增派生函数：冷冻泵流量 `Q ÷ (4.187 × ΔT_chw)`、冷却泵流量 `Q × (1+1/COP) ÷ (4.187 × ΔT_cw)`、冷却塔流量 = 冷却泵流量；验证：默认配置下大机 2,018.25 / 2,314.03 / 2,314.03 L/s（±0.05）
- [x] 1.3 请求模型移除 `COP_chiller_BCH/SCH`、`Gr_pump_chw_*`、`Gr_pump_cw_*`、`Gr_tower_*` 共 7 个字段；验证：携带这些字段的请求返回 422 且指明其为派生值
- [x] 1.4 后端派生并注入：仿真开始时计算上述派生量，写入 `station_info` 与 `meta.parameters`；验证：`meta.parameters` 中的 COP 与三个流量等于 1.1/1.2 的结果
- [x] 1.5 `meta.displayOnly` 对新结果为空，`displayOnlyDeviations` 为空对象；验证：默认配置跑一次后该两字段为空，报告不出现"仅展示"

## 2. 冷却塔设计功率参与计算（D3）

- [x] 2.1 `Tower` 增加输出归一：`k = 设计功率 ÷ 模型在设计点功率`，实际风机功率 = 模型输出 × k；验证：设计工况下风机功率等于设计功率（误差 < 1e-6）
- [x] 2.2 归一系数对模型功率加下限保护，并写入结果元信息备查；验证：构造极端设计功率（如 0.01 kW）时不出现除零或 Inf，且结果中记录 k
- [x] 2.3 修改塔设计功率后全年塔耗电量按比例变化；验证：设计功率 ×2 后塔耗电量约为原值 ×2（误差 < 1%）
