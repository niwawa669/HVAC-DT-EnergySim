# 提案：冷源站设计方案页的参数来源重构，并让报告与该页逐项一致

## Why

新建项目第二步「冷源站设计方案」目前有四处口径不对：

1. **冷机 COP 是手工填的**（默认 5.5 / 5.0），而它是冷机模型在设计工况下的固有属性，手填既无依据、也与实际参与计算的模型对不上
2. **水泵流量是手工填的**，本应由"额定制冷量 + COP"推出
3. **冷却塔设计水流量与冷却泵流量不一致**：当前大机塔为 4,000 L/s，而冷却泵只有 2,522 L/s，塔的水量是泵的 1.6 倍，物理上不成立
4. 报告里的**加机优先级序列显示为 `[21126.0, 42252.0]`**，与设计页的"小机/大机额定制冷量"没有建立明确的对应关系

结果是：同一套设计参数在不同页面取值口径不一致，用户无法判断哪一个才是"实际参与计算的值"。

## What Changes

**设计页的参数来源重构**

| 参数 | 变化 |
|---|---|
| 冷机 COP | 手工输入 → **由冷机模型在设计工况计算**（满负荷、冷冻水 12/7 ℃、冷却水 30/35 ℃），只读展示 |
| 冷冻泵设计流量 | 手工输入 → **Q ÷ (4.187 × ΔT_chw)** |
| 冷却泵设计流量 | 手工输入 → **Q × (1 + 1/COP) ÷ (4.187 × ΔT_cw)**（冷凝负荷 = 制冷量 + 冷机功率） |
| 冷却塔设计水流量 | 手工输入 → **等于冷却泵设计流量** |
| 冷却塔设计功率 | 保留手工输入，并**真正参与计算**（见下） |

以默认配置（放大系数 20、7 大机 + 1 小机）为例：

| 项 | 大机 | 小机 |
|---|---|---|
| 额定制冷量 | 42,252 kW | 21,126 kW |
| 模型 COP（设计工况） | **6.8235** | **6.8235** |
| 冷冻水流量 | **2,018.25 L/s** | **1,009.12 L/s** |
| 冷却水流量 | **2,314.03 L/s** | **1,157.01 L/s** |
| 冷却塔水流量 | **2,314.03 L/s**（= 冷却泵） | **1,157.01 L/s** |

**取消"仅展示"分类**

设计页上不再存在"仅展示、不参与计算"的参数。冷机 COP 变为派生只读值，冷却塔设计功率变为真正生效的输入——两者都不再需要这个标注。

**报告与设计页逐项一致**

- 加机优先级序列 SHALL 等于「[小机额定制冷量, 大机额定制冷量]」，并在报告中以可读形式呈现（如 `小机 21,126 kW → 大机 42,252 kW`），不得出现裸数组
- 报告中的大/小机额定制冷量、COP、泵流量、塔流量与塔功率 SHALL 与设计页对应字段逐项相等
- 报告参数表的取值 SHALL 是"实际参与计算的值"，而不是提交时的基准值（已修，本次一并纳入契约）

## Capabilities

### Modified Capabilities

- `equipment-config`：COP / 泵流量 / 塔流量改为派生值；塔设计功率改为生效参数并定义其参与方式；删除"仅展示"这一分类
- `simulation-result`：参数快照记录的 COP 与各项流量改为模型算得的实际值
- `simulation-report`：参数表与设计页逐项一致；加机优先级以可读形式呈现

## Impact

- `src/main/src/views/ProjectNew.vue`：五个字段改为只读派生，去掉"仅展示"标注
- `src/apiserver/app/services/algorithm_wrapper.py`：设计工况下调用冷机模型求 COP；派生泵塔流量；快照写入实际值
- `src/algorithm/station.py` / `channel.py` / `tower_model.py`：塔设计功率参与计算的折算
- `src/apiserver/app/models/schemas.py`：字段校验与默认值
- `src/apiserver/app/services/report_service.py`：加机优先级的可读呈现

## 待确认：冷却塔设计功率如何"参与计算"

塔的风机功率目前由冷却塔模型算出，设计功率只作标称校核。去掉"仅展示"后它必须真正影响结果，否则违反「参数生效原则」。三种做法：

- **A（推荐）按设计点归一**：`k = 设计功率 ÷ 模型在设计点的功率`，实际风机功率 = 模型输出 × k。设计工况下恰等于用户输入，部分负荷特性仍由模型给出
- **B 直接取代模型功率**：风机功率恒等于设计功率，模型只给出水温度。简单但丢失部分负荷特性
- **C 保留模型值**：设计功率仅作校核——这就必须保留"仅展示"标注，与本需求冲突

默认按 **A** 实现，若选 B 或 C 请说明。

## 验收口径

以默认配置运行并生成报告，报告第 3 章应满足：

```
大机额定制冷量      42,252.00 kW
大机 COP             6.8235            ← 与模型一致
大机冷冻泵设计流量   2,018.25 L/s
大机冷却泵设计流量   2,314.03 L/s
大机冷却塔设计流量   2,314.03 L/s      ← 等于冷却泵
大机冷却塔设计功率   由用户输入
加机优先级           小机 21,126 kW → 大机 42,252 kW
```
